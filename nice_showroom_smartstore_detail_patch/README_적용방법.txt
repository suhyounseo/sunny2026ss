NICE 쇼룸 스마트스토어 보완 상세정보 반영 패치

적용 방법
1. 압축을 풀고 products.json, app.js, style.css, index.html 4개 파일을 기존 쇼룸 폴더에 덮어쓰기 합니다.
2. GitHub Desktop에서 변경파일 확인 후 commit/push 합니다.
3. 배포 후 상품 상세를 열어 사이즈표와 착용정보가 표시되는지 확인합니다.
