NICE 상세페이지 20차 최종 통합본

반영 내용:
1. 상세페이지 상단 브랜드명 NICE COLLECTION 유지
2. 이미지 좌우 화살표가 사진을 덜 가리도록 조정
3. 사진 영역을 더 넓게 보이도록 수정
4. 제품정보 영역 폭을 줄여 전체 레이아웃 정리
5. 사이즈가이드/착용정보가 있는 상품은 컬러·사이즈·소재 요약 박스 숨김
6. 상세 제품정보가 없는 상품만 컬러·사이즈·소재 요약 박스 노출
7. 기존 상세 이미지 좌우 이동 기능 유지

적용 방법:
1. ZIP 압축 풀기
2. app.js / style.css / index.html / products.json 파일을 기존 쇼룸 폴더에 덮어쓰기
3. GitHub Desktop에서 변경 확인
4. Commit 메시지: Apply detail page refinement 20
5. Push origin
6. 쇼룸에서 Ctrl + F5 새로고침
