# 제시카 쇼룸 반영본 - 2026-08-08

이 ZIP을 풀어서 GitHub 저장소 루트에 덮어쓰기 후 Commit / Push 하면 됩니다.

포함 파일:
- products.json : 제시카 상품 9개 반영/교체
- app.js : 캐시 버전 jessica0808_1 반영
- index.html : app/style 캐시 버전 jessica0808_1 반영
- assets/jessica/ : 이번에 신규/교체되는 제시카 이미지
- jessica_products_review_final.csv : 상품명/상세설명/사이즈/착용정보 검토용
- jessica_image_order_report.csv : M 메인컷, P 제품컷 기준 이미지 배열 확인용

반영 핵심:
- JES-309와 JES-326은 같은 디자인 다른 컬러로 묶음 처리했습니다.
  - JES-309: 살구 / 77 재고
  - JES-326: 블랙 / 77 재고
- JES-309는 기존 이미지를 사용하지 않고, 이번에 받은 새 이미지로 교체했습니다.
- 이미지 배열은 파일명 M을 메인컷으로 우선 배치하고, P는 제품컷으로 이어 배치했습니다.
- 거래처 제품정보 원본 이미지는 고객 화면에 넣지 않았고, 사이즈/착용정보는 테이블 데이터로만 반영했습니다.
- JES-109 신규 자료도 포함했습니다.

검토 필요:
- 가격은 제시카 기존 기준 75,000원으로 통일했습니다. 다르면 products.json 가격만 수정하면 됩니다.
- 상품명/상세설명은 고객 노출용으로 정리했으며 거래처명은 고객 문구에 넣지 않았습니다.
