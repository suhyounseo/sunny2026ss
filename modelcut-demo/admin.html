NICE · MODELCUT GENERATION

모델컷 생성 요청

실제 상의·하의 이미지를 역할별로 정리해 생성 요청 패키지를 만들고, 외부 생성 결과를 다시 올려 검토합니다.

검토판 열기
  1. 1단계상의/하의 이미지 넣기
  2. 2단계상품 분석 만들기
  3. 3단계모델컷 생성 요청 만들기
  4. 4단계생성 결과 업로드하기
  5. 5단계검토판에서 확인하기

작업 기본 정보

1단계: 상의/하의 이미지 넣기

각 이미지 아래에서 역할을 지정하세요. 역할 정보는 생성 프롬프트와 manifest에 반영됩니다.

상의 이미지 최대 5장

정면 / 후면 / 디테일 / 원단컷 권장

하의 이미지 최대 5장

정면 / 후면 / 디테일 / 원단컷 권장

참고 이미지 최대 3장 · 선택

포즈 / 배경 / 거래처 분위기 참고용

선택 입력 열기 — 상품명·컬러·소재·디테일·기장·실루엣

비워도 분석 기본값이 생성됩니다. 실제 제품 정보를 알고 있다면 더 정확하게 입력하세요.

2단계: 상품 분석 만들기

입력 정보와 이미지 역할을 바탕으로 생성 요청에 사용할 상품 보존 규칙을 정리합니다.

상품 분석 완료

  • 실제 제품 이미지 기준
  • 기장·실루엣 보존
  • 핵심 디테일 보존
  • 없는 요소 생성 금지

3단계: 모델컷 생성 요청 만들기

외부 이미지 생성툴 또는 코덱스에 전달할 프롬프트·요청 JSON·이미지 역할 manifest를 만듭니다.

생성 요청 패키지 준비 완료

  • 상품 일치도 우선
  • 실제 없는 컬러·장식 금지
  • 이미지 역할 지시 포함
  • 정면 전신 모델컷 요청
generation_prompt.txt실전형 생성 프롬프트
generation_request.json작업·분석·이미지 목록
reference_images_manifest.json이미지 역할 manifest
생성 요청 프롬프트 미리보기

4단계: 생성 결과 업로드하기

외부 생성툴 또는 코덱스에서 만든 모델컷을 다시 올리세요. 최대 3개 후보가 한 검토 카드에 표시됩니다.

생성된 모델컷 업로드 최대 3장

후보 1 / 후보 2 / 후보 3으로 검토판에 연결됩니다.

5단계: 검토판에서 확인하기

저장 후 실제 제품 이미지, 생성 요청 요약, 생성 결과 후보를 한 카드에서 확인합니다.

검토판에서 확인하기

이미지와 작업은 이 브라우저의 IndexedDB에 저장됩니다. 생성 요청 파일과 작업 JSON을 함께 백업하세요.
