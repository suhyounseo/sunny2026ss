모델컷 생성 스튜디오

실제 상의·하의 이미지를 진실 소스로 삼아 요청을 만들고, 로컬 생성 서버에서 후보를 실행한 뒤 검토판까지 자동 연결합니다.

작업 기본 정보

1단계: 상의/하의 이미지 넣기

각 이미지 아래에서 역할을 지정하세요. 역할 정보는 생성 프롬프트와 manifest에 반영됩니다.

상의 이미지 최대 5장

정면 / 후면 / 디테일 / 원단컷 권장

하의 이미지 최대 5장

정면 / 후면 / 디테일 / 원단컷 권장

참고 이미지 최대 3장 · 선택

포즈 / 배경 / 거래처 분위기 참고용

고급 설정 열기 — 상품 속성·허용 컬러·후보 수·추가 메모

비워도 분석 기본값이 생성됩니다. 실제 제품 정보를 알고 있다면 더 정확하게 입력하세요.

2단계: 상품 분석 만들기

입력 정보와 이미지 역할을 바탕으로 생성 요청에 사용할 상품 보존 규칙을 정리합니다.

상품 분석 완료

  • 실제 제품 이미지 기준
  • 기장·실루엣 보존
  • 핵심 디테일 보존
  • 없는 요소 생성 금지

3단계: 모델컷 생성 요청 만들기

요청 패키지를 만든 뒤 로컬 생성 서버에서 실제 후보 생성을 실행합니다. API 키는 브라우저가 아니라 서버의 .env에서만 읽습니다.

준비 전

먼저 상품 분석과 생성 요청을 만드세요.

생성 요청 패키지 준비 완료

  • 상품 일치도 우선
  • 실제 없는 컬러·장식 금지
  • 이미지 역할 지시 포함
  • 정면 전신 모델컷 요청
generation_prompt.txt실전형 생성 프롬프트
generation_request.json작업·분석·이미지 목록
reference_images_manifest.json이미지 역할 manifest
생성 요청 프롬프트 미리보기

4단계: 생성 결과 확인·저장

서버 생성 완료 시 후보가 자동으로 채워집니다. 외부 생성 결과가 있다면 아래에서 수동 업로드할 수도 있습니다.

생성 결과 업로드 최대 3장

자동 생성 후보 또는 수동 업로드 후보 1 / 2 / 3이 검토판에 연결됩니다.

5단계: 검토판에서 확인하기

저장 후 실제 제품 이미지, 생성 요청 요약, 생성 결과 후보를 한 카드에서 확인합니다.

검토판에서 확인하기
